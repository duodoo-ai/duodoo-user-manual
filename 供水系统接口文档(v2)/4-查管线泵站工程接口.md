### 管线列表接口
功能说明:
- 提供完整的管线信息查询，包含基础信息、运行状态、关联泵站等
- 支持分页、排序、状态筛选和工程筛选
- 数据包含完整的泵站设备信息
- 支持角色隔离：项目负责人查看所有，供水服务商只查看自己的数据
- 特点：返回完整信息，包括所有管线和泵站的详细信息
- 适用场景：详细查看、导出数据、系统管理

认证方式: Bearer Token (JWT)
请求方法: GET
响应格式: JSON
请求路径: `/api/v2/pipeline/list`

请求参数:
- page (可选): 页码，默认1
- limit (可选): 每页记录数，默认20，最大100
- project_id (可选): 工程ID筛选，查询指定工程下的管线
- status (可选): 管线状态筛选，支持多个状态逗号分隔
- sort_by (可选): 排序字段，默认create_date
- sort_order (可选): 排序方向，asc/desc，默认desc
- include_pump_stations (可选): 是否包含泵站详情，true/false，默认true
- include_project_info (可选): 是否包含工程信息，true/false，默认true

响应结构:
{
	"status": 200,
	"msg": "成功",
	"success": true,
	"data": {
		"pipelines": [...],  # 管线列表
		"pagination": {...}  # 分页信息
	},
	"timestamp": "2025-01-01 12:00:00"
}

## 参数说明

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `page` | int | 1 | 页码（从1开始） |
| `limit` | int | 20 | 每页记录数（最大100） |
| `project_id` | int | - | 工程ID筛选 |
| `status` | string | - | 状态筛选（逗号分隔多个状态） |
| `sort_by` | string | create_date | 排序字段 |

| `include_pump_stations` | bool | true | 是否包含泵站详情 |
| `include_project_info` | bool | true | 是否包含工程信息 |

2. **调整URL**：根据实际部署环境调整`localhost:3000`为正确的Odoo实例地址
3. **参数验证**：API会自动验证参数有效性，无效参数会返回400错误
4. **权限控制**：接口支持基于用户角色的数据隔离（项目负责人/供水服务商）
5. **CORS支持**：接口已配置CORS，支持跨域调用
