### 用户登录更新接口
要求：
- 接口路径：/api/v1/user/update
- 请求方法：POST
- 请求参数：
      - session_id：会话ID    # 会话ID，用于验证用户身份
      - geo_latitude：用户当前位置纬度    # 用户当前位置纬度
      - geo_longitude：用户当前位置经度    # 用户当前位置经度
      - geo_zoom_ratio：用户当前缩放比例    # 用户当前缩放比例
  - 接口测试：
  curl -X POST http://localhost:3000/api/v1/user/update \
  -H "Content-Type: application/json" \
  -d '{
      "session_id": "m8cXuzZOSf5CPIJqL6tKe19rAIjYG_MAOQpoTpG1eQlV8CXu4SSw6guo_8KSI6QQ66D-ibNQkFerR6TFN_b9",     
      "geo_latitude": 31.2304,    # 用户当前位置纬度
      "geo_longitude": 121.4737,    # 用户当前位置经度
      "geo_zoom_ratio": 12.5    # 用户当前缩放比例
  }'
    - 响应参数：
    {
        "status": 200,    # 成功状态码
        "msg": "User location updated successfully",    # 成功消息
        "success": true    # 成功标志
    }
