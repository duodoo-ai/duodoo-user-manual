# H2S浓度监测接口文档

## 接口概述
本接口用于获取指定管线的H2S浓度监测数据，包括各监测点的最新值、历史趋势及状态信息。

---

## 接口详情

### 基础信息
| 属性 | 值 |
|------|----|
| **接口路径** | `/api/v1/pipelines/{pipeline_id}/h2s_monitoring` |
| **请求方法** | `GET` |
| **认证方式** | Bearer Token (JWT) |
| **跨域支持** | 是 (已处理CORS) |
| **响应格式** | JSON |

### 请求参数
#### 路径参数
| 参数名 | 类型 | 必填 | 描述 |
|--------|------|------|------|
| `pipeline_id` | int | 是 | 管线唯一标识ID |

#### 请求头
| 头部字段 | 必填 | 描述 |
|----------|------|------|
| `Authorization` | 是 | Bearer Token格式：`Bearer <your_token>` |

---

## 响应结构

### 成功响应 (HTTP 200)
```json
{
  "status": 200,
  "msg": "Success",
  "pipeline_id": 123,
  "pipeline_name": "西线主供水管道",
  "write_date": "2025-07-09 10:30:45",
  "monitoring_points": [
    {
      "h2s_sn": "SN-2024-001",
      "h2s_value": 0.15,
      "monitoring_time": "2025-07-09 10:25:30",
      "status": "normal"
    },
    {
      "h2s_sn": "SN-2024-002",
      "h2s_value": 0.08,
      "monitoring_time": "2025-07-09 10:24:45",
      "status": "warning"
    }
  ]
}
```

#### 字段说明
| 字段 | 类型 | 描述 |
|------|------|------|
| `status` | int | HTTP状态码 (200=成功) |
| `msg` | string | 操作结果消息 |
| `pipeline_id` | int | 管线ID |
| `pipeline_name` | string | 管线显示名称 |
| `write_date` | datetime | 管线最后更新时间 (格式: YYYY-MM-DD HH:MM:SS) |
| `monitoring_points[]` | array | H2S监测点数据集合 |
| → `h2s_sn` | string | 监测点序列号 (空值返回"UNKNOWN_SN") |
| → `h2s_value` | float | H2S浓度值 (空值返回0.0) |
| → `monitoring_time` | datetime | 监测时间 (格式: YYYY-MM-DD HH:MM:SS) |
| → `status` | string | 监测点状态 ("normal", "warning", "error", 空值返回"unknown") |

## 权限说明
1. **基础权限**：
   - 所有用户必须通过有效的Bearer Token认证
   - 用户账号必须在系统中存在且有效

2. **管线访问权限**：
   - 普通用户：可访问所有管线
   - 供水公司用户(`group_water_supplier`)：仅可访问自己公司(partner_id)关联的管线

---

## 数据特点
1. **监测点排序**：
   - 监测点数据按`monitoring_time`倒序排列（最新数据在前）
   
2. **空值处理策略**：
   - `h2s_sn`空值 → "UNKNOWN_SN"
   - `h2s_value`空值 → 0.0
   - `status`空值 → "unknown"

3. **数据时效性**：
   - 响应中包含管线最后更新时间(`write_date`)，可用于客户端缓存验证

## 调用示例
### cURL请求
```bash
curl -X GET \
  'localhost:3000/api/v1/pipelines/1/h2s_monitoring' \
  -H 'Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...'
```

### JavaScript调用 (Fetch API)
```javascript
async function getH2SData(pipelineId) {
  try {
    const response = await fetch(
      `/api/v1/pipelines/${pipelineId}/h2s_monitoring`,
      {
        method: 'GET',
        headers: {
          'Authorization': 'Bearer YOUR_ACCESS_TOKEN'
        }
      }
    );
    
    if (!response.ok) {
      throw new Error(`HTTP error! status: ${response.status}`);
    }
    
    const data = await response.json();
    console.log('H2S Monitoring Data:', data);
    
    // 处理监测点数据
    data.monitoring_points.forEach(point => {
      console.log(`Sensor ${point.h2s_sn}: ${point.h2s_value} ppm`);
    });
    
    return data;
  } catch (error) {
    console.error('Fetch Error:', error);
    return null;
  }
}

// 调用示例
getH2SData(123);
```

## 注意事项
1. **认证要求**：
   - 所有请求必须在Header中包含有效的Authorization Token
   - Token过期时间遵循系统安全策略

2. **数据更新频率**：
   - 监测数据更新频率取决于传感器上报周期（通常5-30分钟）
   - 客户端建议设置定时刷新（推荐间隔10分钟）

3. **错误处理建议**：
   - 401错误：引导用户重新登录获取新Token
   - 403错误：提示用户权限不足
   - 404错误：检查管线ID是否正确
   - 500错误：记录错误信息并提示用户稍后重试

4. **跨域支持**：
   - 接口已处理CORS，前端可直接跨域调用
   - OPTIONS预检请求已支持

5. **性能优化**：
   - 监测点数据按时间倒序返回，前端无需额外排序
   - 响应数据已精简，只包含必要字段

> 本接口数据适用于H2S浓度监测看板、实时预警系统和水质分析报告等场景
