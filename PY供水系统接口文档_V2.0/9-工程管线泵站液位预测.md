
## 创建的API接口文件

实现了以下功能：

### 1. 工程级预测接口
```python
@http.route('/api/v2/level/predict/project/<int:project_id>/all-pump-stations', ...)
def predict_project_all_pump_stations(self, project_id: int, **kwargs)
```
- **功能**：预测工程中所有管线的所有泵站液位
- **路径**：`/api/v2/level/predict/project/{project_id}/all-pump-stations`
- **方法**：GET

### 2. 管线级预测接口
```python
@http.route('/api/v2/level/predict/pipeline/<int:pipeline_id>/all-pump-stations', ...)
def predict_pipeline_all_pump_stations(self, pipeline_id: int, **kwargs)
```
- **功能**：预测指定管线中的所有泵站液位
- **路径**：`/api/v2/level/predict/pipeline/{pipeline_id}/all-pump-stations`
- **方法**：GET

### 3. 泵站级预测接口
```python
@http.route('/api/v2/level/predict/pump-station/<int:pump_station_id>', ...)
def predict_single_pump_station(self, pump_station_id: int, **kwargs)
```
- **功能**：预测单个泵站的详细液位信息
- **路径**：`/api/v2/level/predict/pump-station/{pump_station_id}`
- **方法**：GET

### 4. 多时间点预测接口
```python
@http.route('/api/v2/level/predict/pump-station/<int:pump_station_id>/multi-time', ...)
def predict_multi_time_points(self, pump_station_id: int, **kwargs)
```
- **功能**：预测未来1-8小时每个小时的液位变化
- **路径**：`/api/v2/level/predict/pump-station/{pump_station_id}/multi-time?hours=8`
- **方法**：GET

## 接口功能特点

### 1. 完整的认证机制
- 使用Bearer Token认证
- 支持CORS跨域请求
- 用户权限验证

### 2. 详细的预测信息
每个预测结果包含：
- **当前液位**：当前水位高度（m）
- **预测液位**：8小时后水位高度（m）
- **预测水量**：8小时后水量（m³）
- **置信度**：预测准确度（0-1）
- **风险等级**：critical/high/medium/low
- **模型类型**：使用的预测模型
- **时间戳**：预测时间

### 3. 批量处理能力
- 支持工程级批量预测
- 支持管线级批量预测
- 错误处理和成功统计

### 4. 风险预警功能
基于预测液位自动计算风险等级：
- **critical**：严重风险（接近停止水位）
- **high**：高风险（接近预警水位）
- **medium**：中等风险
- **low**：低风险（接近理想水位）
