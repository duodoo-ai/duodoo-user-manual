# 告警系统API接口文档

## 概述

本文档描述告警系统的REST API接口，提供告警数据的查询、统计和详情获取功能。所有接口都使用HTTP GET方法，需要用户认证。

## 基础信息

- **API版本**: v2
- **认证**: 用户会话认证（Cookie）
- **响应格式**: JSON
- **字符编码**: UTF-8

## 接口列表

### 1. 获取告警列表

**功能描述**: 获取告警列表，支持分页、筛选和排序。
**接口地址**: `GET /api/v2/alert/list`

#### 请求参数

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| `page` | int | 否 | 1 | 页码，从1开始 |
| `limit` | int | 否 | 20 | 每页记录数 |
| `severity` | string | 否 | - | 严重程度筛选，逗号分隔多个值。可选值: `info`, `warning`, `error`, `critical` |
| `alert_status` | string | 否 | - | 告警状态筛选，逗号分隔多个值。可选值: `normal`, `warning`, `alert`, `acknowledged`, `resolved`, `closed` |
| `project_id` | int | 否 | - | 按项目ID筛选 |
| `pipeline_id` | int | 否 | - | 按管线ID筛选 |
| `pump_station_id` | int | 否 | - | 按泵站ID筛选 |
| `date_from` | string | 否 | - | 开始日期，格式: YYYY-MM-DD |
| `date_to` | string | 否 | - | 结束日期，格式: YYYY-MM-DD |
| `alert_type` | string | 否 | - | 告警类型筛选，逗号分隔多个值。可选值: `level`, `pump`, `pressure`, `flow`, `temperature`, `device`, `system` |
| `active` | boolean | 否 | - | 是否只获取活跃告警 |
| `order_by` | string | 否 | `alert_date desc` | 排序字段，格式: `field_name asc/desc`。支持字段: `id`, `alert_date`, `severity`, `create_date`等 |

#### 成功响应 (200 OK)

### 5. curl测试命令

**curl测试命令**:

curl -X GET "http://localhost:3000/api/v2/alert/list" \
-H "Authorization: Bearer your_session_id"

# 获取第一页20条记录
curl -X GET "http://localhost:3000/api/v2/alert/list?page=1&limit=20" \
-H "Authorization: Bearer your_session_id"

# 获取危急和高严重程度的告警

-H "Authorization: Bearer your_session_id"
