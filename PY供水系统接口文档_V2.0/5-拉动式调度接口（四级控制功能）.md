## 概述

为前端大屏提供的完整设备远程控制接口，提供完整的四级控制功能：工程级、管线级、泵站级、自动调度级。
1. 工程级控制：一键启动整个工程的所有管线
2. 管线级控制：启动指定管线中的所有水泵
3. 泵站级控制：启动指定泵站中的水泵
4. 自动调度级控制：基于液位状态智能调度上游管线

## 基础信息

- **认证方式**: Bearer Token (Authorization: Bearer <token>)
- **响应格式**: JSON
- **CORS支持**: 是

## 接口文档说明：

### 1. 读取泵站监测数据接口
**端点**: `GET /api/v2/pump-station/<int:pump_station_id>/monitor`

**功能**: 获取指定泵站的完整监测数据，包括：
- 流量信息（实时流量、累计流量、额定流量）
- 压力信息（泵前压力、泵后压力，自动转换为Pa）
- 动力系统数据（发动机转速、油温、剩余油量、预计工作时间、电池电量）
- 设备保养信息（上次保养、下次保养、维护状态）
- 告警状态（H₂S监测、活动告警）
- 环境数据（温度、湿度、风速等）
- 可选的历史数据

**参数**:
- `include_history`: 是否包含历史数据（true/false）
- `data_points`: 历史数据点数（默认10）

### 2. 更新泵站设置接口
**端点**: `POST /api/v2/pump-station/<int:pump_station_id>/settings/update`

**功能**: 更新泵站的运行参数设置
- 目标发动机转速（RPM）
- 目标泵前压力（Pa）
- 目标泵后压力（Pa）
- 操作模式（可选）

**请求体**:
```json
{
    "target_engine_speed_rpm": 2200,
    "target_inlet_pressure_pa": 250000,
    "target_outlet_pressure_pa": 400000,
    "operation_mode": "auto",
    "validate_only": false
}
```

### 3. 批量读取泵站数据接口
**端点**: `POST /api/v2/pump-station/batch-monitor`

**功能**: 批量获取多个泵站的监测数据，适合大屏显示

**特点**:
1. **单位转换**: 自动将bar转换为Pa（1 bar = 100,000 Pa）
2. **数据验证**: 完整的参数验证和合理性检查
3. **错误处理**: 企业级的错误处理和日志记录
4. **性能优化**: 批量读取接口支持最多50个泵站
5. **安全性**: 完整的身份验证和权限检查
6. **审计追踪**: 所有操作记录到控制日志

**CORS支持**: 所有接口支持跨域请求，适合前端大屏调用
