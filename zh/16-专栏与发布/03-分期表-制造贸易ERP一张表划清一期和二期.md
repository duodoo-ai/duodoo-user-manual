**标题：【分期表】制造+贸易上 ERP：一张表划清一期和二期**

> 专栏「工贸 ERP · 分期与验收」第 3 篇 · 2026-10 发布  
> 第 01 篇：[干了19年IT…ERP一期烂尾的真相](./01-干了19年IT-我看透了ERP一期烂尾的真相.md) · 第 02 篇：[【边界】「一期」塞太多…](./02-边界-一期塞太多不是省钱是烂尾的开始.md)

上篇 **【边界】** 只讲一件事：口头「一期全包」为什么必烂尾。这篇给一张能打印、能贴进合同附件的 **默认分期表**——范围限定在 **进销存、财务、主数据、人事考勤、生产与成本、跨境业财** 这些 ERP 里最常见的模块；制造 + 贸易（含轻加工）都适用。某友、某蝶、开源 Odoo，**玩法一样**：先划一期二期，再谈人天。

### 这张表解决什么

**谁用**：老板拍板范围；IT 写 SOW、合同附件或立项邮件；乙方 PM 对照别超卖。  
**怎么用**：表是 **默认建议**，不是法律条文。纯贸易盯前三行 + 主数据；有车间重点看生产、成本两行；出海基地在「跨境」一行单独开会，别和国内工厂硬绑同一期签字。  
**不覆盖什么**：车间设备联网、泵站大屏、SCADA 与 ERP 的对接——那是另一条项目线，**不要和一期 ERP 绑在同一个签字范围里**；本文表只帮你们把 **账、单、人、货** 理顺。

烂尾场景和财务收口见 [【边界】](./02-边界-一期塞太多不是省钱是烂尾的开始.md)；签合同前打勾单见下篇 **【七件事】**（待发布）。

### 主表（7 行）+ 怎么读

| 能力模块 | 建议一期 | 建议二期 | 备注（为什么） |
|----------|:--------:|:--------:|----------------|
| 进销存 / 采购销售流程 | ✅ | | 先能关经营账 |
| 基础财务 / 应收应付 | ✅ | | 别和进销存长期两套账 |
| 主数据（物料、客户、供应商） | ✅ | | 谁录入、谁审核，写名字 |
| 人事考勤 / 异构打卡 | 视企业 | ✅ 常见 | 人多、多地、老考勤机时常拖一期 |
| 生产订单 / MES / 车间 | | ✅ | 依赖产线稳定、工艺定版 |
| 成本核算 / 标准成本 | | ✅ | 量产稳了再上，否则数字天天改 |
| 跨境多法人 / 当地开票合规 | 视企业 | ✅ 常见 | 合规路径长，别和「先关账」绑死 |

**进销存 + 基础财务 + 主数据** — 三件套是一期的「最小可验收单元」。销售要的是能下单、能出库、能开票（国内）或能走到财务认可的应收；财务要的是应收应付能收口、月底敢认数。主数据不落地，后面每个模块都在垃圾数据上跑——合同里除了模块名，还要写清 **历史清洗截止日**、**终审人**，以及物料编码是「沿用旧码」还是「统一重编」。我见过太多项目，系统装好了，三个月还在争论客户名称要不要加后缀，那就是主数据没在一期锁边界。

**人事考勤** — 表上写「视企业」，是因为国内轻加工有时一期就要算薪关账；出海工厂又常把考勤当关账前提（老打卡机、无标准接口、班次乱，IT 要单独排期）。我的习惯：**考勤若一期纳入，必须写进附件并单独立项**（数据来源、接口或导入规则、算薪规则），别藏在「进销存赠送」里。人事说「就是个表」，财务月底对不上工时，IT 照样背锅。

**生产 / MES / 成本** — 老板最爱说「一步到位」。车间还在改工艺、BOM 天天变，标准成本就是摆设。一期先把 **采购—入库—领料—销售出库** 和财务对得上；制造深度、工单、复杂成本 **书面押二期**，触发条件写「产线连续稳定量产」「BOM 变更率低于某阈值」之类可观测指标。轻加工可以先 **简单领料 + 手工报工** 过渡，但别把「MES 全覆盖」写进一期验收标准。

**跨境与当地合规** — 多法人、当地开票、薪酬社保规则，往往比多开一个仓库更耗时间。可以一期只做 **国内主体关账**；海外主体单独里程碑，避免国内 UAT 被海外财务链卡住。海外财务怎么进蓝图、UAT 怎么测到凭证，[【边界】](./02-边界-一期塞太多不是省钱是烂尾的开始.md) 里写过，这篇不展开；表上「视企业」那一格，务必开会填成 **「本期签字主体」** 名单，而不是「全球一起上」。

### 纯贸易怎么读表

只看 **前三行 + 主数据** 即可。别被销售带去做车间、别顺手答应 CRM 全流程、费控报销「以后再加」却偷偷塞进一期范围。  
贸易公司最大的坑仍是 **平行账**：系统能跑单，财务月底还在 Excel 调运费、返利、汇差——一期就要写 **第一个只信系统的账期**，并写清哪些调整必须在系统里留单据。  
考勤若人数少、规则简单，可以一期；若多地分公司、销售提成算法复杂，果断二期，别拖死进销存上线。贸易型公司一期验收，我建议老板只问一句：**「从哪个月报表，财务敢只用系统数开会？」** 答不出来，表还没读透。

### 有车间怎么读表

**生产、成本坚决二期** 是常见默认，但不是偷懒。一期要让仓库、采购、财务认同一套物料和单据；车间可以先 **手工报工 + 简单领料** 跑通，别一上来 MES 全模块。  
等 BOM 稳定、返工率下来，再开二期范围会——那时上生产订单、工时、标准成本，财务才愿意签字。有车间的企业，一期还要避免 **「仓库上了扫码，车间没规则」**：仓库数据准了，车间领料还是口头，月底照样对不上。一期至少约定 **领料与出库的单一数据源**，车间复杂逻辑留给二期。

### 三个最容易误塞「一期」的模块

**1. 人事考勤**  
人多、多地、外包工、轮班——每多一个变量，导入规则和算薪就多一周。销售说「就是个打卡」，现场往往是异构机、脏数据、人事和财务各一套算法。**要么一期单独立项写清，要么整包二期。**

**2. 生产 / MES**  
老板参观过样板线，回来就要一期全上。没有稳定量产，MES 只能当电子白板。**一期验收标准里别出现「车间全覆盖」**，除非附件里写了工艺范围、工单类型和 UAT 用例。和 **成本模块** 绑在一起更要警惕：成本没定版，生产上了也是空转。

**3. 跨境多法人**  
国内总部催「全球一套数」，当地财务催「先能开票、能过审」。合规链路（科目、发票、薪酬）没定版，硬并进一期，等于把国内进销存也押上赌桌。**分主体、分里程碑**，同一期合同里写清 **签字主体与模块清单**，别用「集团统一实施」一句话糊过去。

### 出海制造基地怎么定（脱敏）

某海外制造基地一期，我们书面咬死：**本期签字 = 进销存 + 基础财务 + 人事考勤（含现场打卡或约定导入方式）+ 相关部门 UAT**；制造深度、标准成本、复杂费用分摊写在 **二期附件**。  
与国内工厂对照：国内可以「先经营账」；海外往往 **财务签字权更重**——蓝图里财务负责人要前置，UAT 要测到凭证和当地硬项，否则「仓储上线了」也不算一期交付。  
备份、升版窗口、国内远程与现场分工，钉在一张待办上；**验收那天要有纸可签**，不是微信群一句「先跑着」。表里的七行，在海外项目里通常 **不会七行全绿**——先把财务能认的几行做实，比 PPT 上全勾选重要。

### 十条写进合同或邮件（每条一句人话）

1. **本表或等价清单作附件**，一期、二期列明模块与验收标准（**仅 ERP 业财制造范围**）。  
2. **主数据**：责任人姓名、历史清洗截止日、审核流程；编码规则变更走变更单。  
3. **纯贸易不硬上 MES**；有车间也不在一期写「全覆盖车间」。  
4. **考勤**：若一期纳入，单独立项（数据来源、规则、与工资过账）；否则写二期触发条件。  
5. **标准成本、复杂分摊** 等量产稳后再开范围会。  
6. **跨境、多法人、当地开票** 不单绑国内一期签字；写清本期签字主体。  
7. **管理报表、经营分析、CRM 深度** 默认二期；一期先把 **法定账与主流程** 关住。  
8. **开源与年费套件同一逻辑**——先边界，再品牌与人天。  
9. **销售口头承诺 = 范围外变更**，走变更单或邮件确认。  
10. **二期触发条件书面化**（例：产线连续 N 月达产、国内关账连续 M 月无重大调整）。

IT 把上面十条贴进立项邮件或合同附件页，比会上跟老板吵「这个算不算一期」省事。十条不必逐字进合同，但 **附件表 + 触发条件 + 变更入口** 三样要有。

### 把表变成你们自己的（简例）

表是默认档。你们可以复印一版，在「备注」栏手写三句话：**本期签字主体**、**第一个只信系统的账期**、**二期开会触发条件**。发给老板和乙方 PM 邮件确认，比重新开两小时会有效。若组织里同时有 **贸易公司 + 工厂 + 海外办事处**，建议 **一张总表、三个附件页** 分主体填，别在一张签字页上混签。
